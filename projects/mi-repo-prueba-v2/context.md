# Contexto del Proyecto: mi-repo-prueba-v2

> Este archivo lo lee el agente al inicio de cada tarea para entender el proyecto.
> Actualízalo cuando haya cambios importantes en la arquitectura o convenciones.

## Descripción

Repositorio de prueba para validar el sistema de agentes de automatización.
Se usa para experimentar con flujos de CI/CD, branches automáticos y PRs generados por agentes de IA.

## Stack

- Sin stack específico — es un repo de prueba genérico

## Convenciones

- Documentación en español
- Archivos Markdown para docs
- Commits en inglés formato Conventional Commits

## Cosas a tener en cuenta

- Este repo es solo para pruebas, no hay código de producción
- No hay tests configurados
- El agente puede crear y modificar cualquier archivo libremente
